# Alliya Desai — editable fictional gift website

This is a small, editable static website project.

## Files
- `index.html` — edit the page text and the Google Form destination.
- `style.css` — edit colours, layout, fonts and spacing.
- `script.js` — optional page behaviour.

## Google Form
The "Open gift form" button currently points to the Google Form link supplied in the conversation.

## Edit on your phone
1. Download and extract this ZIP.
2. Open the files with a code editor app or GitHub's web editor.
3. Change `index.html` for text and links, or `style.css` for appearance.
4. Commit/upload the changed files to your GitHub repository.
5. Redeploy your site on your hosting platform.

## Safety
This is clearly labelled as a fictional security-awareness simulation and is not affiliated with Snapchat or Snap Inc. It does not request, transmit, or store Snapchat passwords, one-time codes, or recovery codes.
